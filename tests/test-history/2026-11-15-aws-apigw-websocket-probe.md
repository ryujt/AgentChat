# 2026-11-15 AWS API Gateway WebSocket 시그널링 사전 실측

공용 서버를 API Gateway WebSocket API + Lambda + DynamoDB 로 올리기 전에, 설계가 기대는 동작을 일회용 스택으로 잰 기록이다.

- 작업 ID: `2026-11-15-aws-apigw-websocket-probe`
- 기준 상태: 브랜치 `main`, 커밋 `a82ed0e`, 미커밋 변경은 `docs/`, `tests/` (설계 문서와 이력). 제품 코드는 아직 없다.
- 환경: AWS 서울 리전(`ap-northeast-2`), 일회용 스택 `agent-chat-probe`, **기본 엔드포인트만** 사용(사용자 지정 도메인 없음). 서버는 Lambda `nodejs24.x`(v24.22.3) arm64 256MB, 런타임 내장 SDK v3 3.1105.0. 클라이언트는 이 PC 의 Node v26.12.1 + `ws` 8.23.0 (브라우저가 아니다).
- 실행 시각: 2026-11-15 11:04 ~ 11:26 KST.
- 참고한 이전 이력: `2026-11-15-pre-implementation-assumptions`. 그 조사는 WebRTC·MCP 쪽이고 AWS 항목이 없어 반영할 것이 없었다.
- 증거 수준: 모두 **탐색 코드**로 한 것이다. 제품 경로 검증이 아니다. 같은 항목은 배포한 제품으로 다시 검증한다(검증 계획의 `V-P1`~`V-P7`).
- 정리: 스택을 지웠다(`DELETE_COMPLETE`). 남은 자원이 없다고 실측 담당이 보고했다.
- 원문 증거: 탐색 코드, 템플릿, 실행 로그, 접근 로그 사본은 세션 임시 폴더(`<scratchpad>/aws-probe`)에 있었고 보존 대상이 아니다. 재현에 필요한 조건과 판정은 이 문서에 남겼다. 계정 ID, 연결 ID 는 적지 않았다.
- 기록 경위: 실측 담당이 결과를 요약으로 넘겼고, 설계 작성 담당이 임시 폴더의 실행 로그와 대조해 이 기록을 썼다. 로그에서 직접 확인하지 못한 값은 "보고"라고 적었다.

미확인으로 남은 것:

- 문서로만 본 값: 최대 연결 2시간, 계정 한도(새 연결 초당 500, 계정 스로틀 초당 10,000·버스트 5,000, 라우트 300, 통합 제한 29초), 런타임 지원 종료일(`nodejs24.x` 2028-04-30, `nodejs22.x` 2027-05-30), Node.js 26 의 공개 프리뷰 상태.
- 로컬 시계와 Lambda 시계의 차이가 `$disconnect` 지연(14~29ms)에 섞여 있다.
- 유휴 시험의 ping 연결에서 마지막 확인 메시지 한 건이 429 를 받았다. 같은 시간에 돌던 스로틀 시험(PRE-AWS-10)의 영향이다. 연결은 살아 있었다.
- 500 으로 사라진 2건에 대해 보낸 쪽이 무엇을 받았는지는 기록에 없다.

# 2026-11-15 W4: 상태와 기록 (`shared-state`, `records`)

작업 묶음 W4([구현 계획](../../docs/design/implementation-plan.md#3-작업-묶음))의 구현과 검증 기록이다. 복제본(로컬 명령과 규칙 판정, 원격 병합, 스냅샷, 지문, 경과 시간), 기록 파일, 최종 보고서를 만들고 `V-U3`, `V-U5` 를 실행했다.

- 작업 ID: `2026-11-15-w4`
- 대상: `src/shared-state/**`, `src/records/**` (각 `contract.ts` 제외)
  - 제품 코드: `shared-state/index.ts`, `replica.ts`, `derive.ts`, `changes.ts`, `records/index.ts`, `paths.ts`, `transcript.ts`, `transcript-reader.ts`, `report.ts`
  - 시험 코드: `shared-state/testing.ts`, `rules.test.ts`, `merge.test.ts`, `cases.test.ts`, `elapsed.test.ts`, `records/testing.ts`, `transcript.test.ts`, `report.test.ts`
- 기준 상태: 브랜치 `main`, 커밋 `a82ed0e` + 작업 트리(미커밋). W0 산출물(`src/protocol/**`, 각 `contract.ts`, `src/boundaries.test.ts`) 위에서 했다. 다른 묶음이 같은 작업 트리에서 동시에 일했다. 그 파일은 읽지도 고치지도 않았다.
- 환경: macOS 27.2.1 arm64 한 대, Node v26.12.1, TypeScript 7.0.2. 파일 시스템은 이 PC 의 APFS.
- 빌드와 실행: `npx tsc -p tsconfig.json --outDir .work/w4/dist` 뒤 `node --test --enable-source-maps ".work/w4/dist/<모듈>/**/*.test.js"`. 공용 `dist` 와 `npm test` 는 쓰지 않았다. `records` 시험의 임시 폴더는 `TMPDIR=<scratch>/tmp` 로 세션 임시 폴더 안에 뒀다(`<scratch>` = 세션 임시 폴더의 `impl/w4/`).
- 증거 수준: **대역**. `shared-state` 는 시각을 인자로 받는 동기 함수뿐이라 가짜 시계와 대역 참가자로 돌렸다. `records` 는 제품의 공개 진입점(`openTranscript`, `writeReport`)을 이 PC 의 실제 파일 시스템(임시 폴더)에 실행했다. 권한과 심볼릭 링크 동작은 macOS 에서만 봤다. 네트워크, 실제 링크, 실제 호스트는 쓰지 않았다. 프로세스를 띄우지 않았다(`node --test` 가 띄우는 시험 프로세스만).
- 참고한 이전 이력:
  - `2026-11-15-w0-contracts`: PROTOCOL-IMPL-R2-01(`packStateFrames` 가 기록 하나라도 걸리면 프레임을 만들지 않는다), PROTOCOL-IMPL-R2-03(`lc` 의 끝과 `INVALID_ARGUMENT`), W0-33(계약을 어긋나게 바꾸면 컴파일이 잡는다). 반영: `applyLocal` 이 만든 기록과 `snapshot()` 이 `packStateFrames` 를 통과하는지를 시험에 넣었다(U-W4-02 이후 모든 실행). `lc` 의 끝은 접지 않고 거절한다. 병합에서도 받은 기록을 `parseStateRecord` 로 다시 본다.
  - `2026-11-15-design-review`: 경과 시간 규칙(두 값을 함께 바꾼다, `test_id` 를 함께 본다)이 미실측이라고 적혀 있다. 반영: `elapsed.test.ts` 와 `cases.test.ts` 가 그 규칙을 본다. 변이로 규칙을 뺐을 때 시험이 잡는지도 봤다(U-W4-08 의 S01~S04).
  - `2026-11-15-pre-implementation-assumptions`, `2026-11-15-aws-apigw-websocket-probe`: 외부 가정의 기록이다. 이 묶음은 외부에 닿지 않아 실행 조건에 쓰지 않았다.
- 원문 증거: 명령 출력은 `<scratch>` 에 있었고 보존 대상이 아니다. 재현에 필요한 명령·시드·판정은 이 문서에 적었다. 채팅 본문, 방 ID, 계정 정보는 없다(시험의 방 ID 는 표본 값이다).

## 구현하면서 정한 것 (설계가 한 가지로 정하지 않은 곳)

통합 담당과 W6 가 알아야 하는 해석이다. 설계의 규칙을 바꾼 것은 없다.

| 곳 | 정한 것 | 이유 |
|---|---|---|
| `STATE_MAX_BYTES` | 그 쓰기로 합계가 상한을 **넘게 되면** `STATE_FULL` 이다(이미 닿은 뒤가 아니라). 기록 수는 2000건이면 거절한다 | 로컬 쓰기로는 스냅샷이 1MiB 를 넘지 않는다. 설계의 근거(1MiB 를 입장 기한 안에 보낸다)에 맞는다 |
| 지금까지 본 가장 큰 `lc` | 병합에서 진 기록(키 기록의 옛 값, 내용 충돌에서 진 쪽)의 `lc` 도 본 값으로 센다. 검증에서 버린 기록과 `overflow` 로 넣지 않은 묶음은 세지 않는다 | "본 뒤에 쓴 기록은 더 크다"를 넓게 지킨다 |
